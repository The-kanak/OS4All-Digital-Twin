## 2. Identified Vulnerabilities & Hardening Applied

1. **Probability Terminology Correction**:
   - Replaced uncalibrated ML "probability" claims with **"Prototype Risk Score: X / 100"** and explicit notice: *"This prototype score is generated from engineered physiological features and is not a clinically calibrated probability."*
2. **Explicit Two-Stream Data Fusion Card**:
   - Added a compact visual representation on the Doctor Dashboard showing: **Static Profile + Dynamic Telemetry + Personal Baseline = Fused Living Digital Twin**.
3. **Gemini Integration with Offline Fallback**:
   - Implemented `GeminiExplanationService` with secure backend-only `GEMINI_API_KEY` configuration and deterministic fallback so the system remains 100% operational offline.
4. **State Transition Traceability**:
   - Added explicit "Previous State $\rightarrow$ Current State" tracking with reasons and drivers for why the virtual patient changed states.
5. **Recovery Scenario Efficacy**:
   - Verified that injecting Scenario 5 (Recovery) demonstrably lowers the risk score, normalizes glycemic variability, and transitions the twin back to `STABLE`.
